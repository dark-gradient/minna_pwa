# Minna no Nihongo — Minna Kotoba PWA

A standalone installable Progressive Web App for vocabulary practice.

## Included
- Lessons 1–20 from the uploaded source
- Single lesson, lesson range, or all available lessons
- Japanese → English, English → Japanese, or mixed direction
- Randomized sessions
- Separate Kaiwa section, excluded from vocabulary pool
- Light/dark mode
- Offline caching after first successful load

## Install on iPhone
1. Host this folder from an HTTPS URL.
2. Open the URL in Safari.
3. Tap Share → Add to Home Screen.
4. Launch **Minna Kotoba** from the Home Screen.

A local `file://` preview cannot install a service-worker PWA; HTTPS hosting is required.
